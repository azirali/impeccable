Навык помогает проверить, что человек действительно может сделать в интерфейсе перед выпуском. Каждая проблема связывается с воспроизводимым сценарием, последствием для пользователя, исправлением и повторной проверкой.

## Установка

```bash
npx skills add azirali/impeccable --skill aziral-ui-release
```

Для ручной установки скопируйте папку `skills/aziral-ui-release` в каталог навыков своего агента. В Codex используйте `$aziral-ui-release`. Это навык с инструкциями; движок, детектор и hooks оригинального Impeccable он не устанавливает.

## Пример запроса

```text
Используй $aziral-ui-release для проверки формы связи на русском,
английском и казахском перед выпуском. Проверь мобильное меню,
клавиатуру, валидацию и длинные тексты. Для проблем укажи воспроизведение,
последствие и подтверждение. Не меняй страницы вне задачи.
```

## Области проверки

| Область | Что подтверждать |
| --- | --- |
| Языки | Настоящие строки RU/EN/KK, символы шрифта, переносы, переходы между языками |
| Касания | Зоны нажатия, перекрывающиеся элементы, прокрутка, отмена жеста |
| Клавиатура | Порядок и видимость фокуса, меню, диалоги, доступность действий |
| Формы | Подписи, ошибки, сохранение ввода, загрузка, успех и сбой |
| Движение и вёрстка | Уменьшенное движение, стабильность элементов, переполнение на узком экране |

Проверка сохраняет границы задачи. Она может быть только обзором или включать исправления, если пользователь их запросил. Визуальные предпочтения отделяются от подтверждённых дефектов.

## Результат

[Шаблон отчёта](skills/aziral-ui-release/references/review-template.md) фиксирует версию, среду, проблемы и повторные проверки. [Пример](examples/release-review-example.md) показывает, как описывать конкретные проблемы, не выдавая непроведённые проверки за успешные.

Если оригинальный детектор Impeccable уже доступен, его результаты можно использовать как дополнительное свидетельство. Вывод о проблеме опирается на воспроизведение и последствие для человека. Отсутствие замечаний детектора не подтверждает работоспособность сценария.

## Участие

Для issue укажите минимальное воспроизведение, язык, устройство, ожидаемое и фактическое поведение. Удалите закрытые данные. Полезны улучшения оценки приоритета, проверки локализации и способы уменьшить ложные срабатывания.
